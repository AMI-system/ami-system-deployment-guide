1.7 Setting the Timer Relay

1.7.1 Set time on timer relay

1. Press the clock key and the MAN key simultaneously to toggle between 12/24 hour clock

mode.

2. Keep the Clock key pressed and then press the D+ key to set day.
3. Keep the Clock key pressed, then press the H+ key to set hour.
a. 00-23 in 24-hour mode
b. 01-12 in 12-hour mode
4. Keep the Clock key pressed, then press M+ key to set minutes.
5. Click the MAN button to get back to the main screen.

1.7.2 Set a schedule

1. Press PR to set the schedule for when AMI will turn ON
2. Press D+ stepwise for day selection as given below.
a. MO TU WE TH FR SA SU (All week days)
b. MO TU WE TH FR SA (Exclude Sunday)
c. MO TU WE TH FR (Exclude Weekends)
d. MO TU WE TH SU (Exclude Friday & Saturday)
e. SA SU (Only Weekends)
f. FR SA (Only Weekends)
g. TU WE TH FR SA SU (Exclude any single day)
h. MO/TU/WE/TH/FR/SA/SU (Include Single day)
i. MO WE FR (Exclude Alternate day)
j. TU TH SA (Exclude Alternate day)
3. Press H+ to edit and increment the hour. Use MAN(-) key to decrement hours.
4. Press PR to set the schedule for when AMI will turn OFF
5. Press D+ stepwise, as above, for day selection. Please note that the OFF day will be the

day after the ON day as it passes 00:00. Eg. If the ON schedule is MO WE FR, the OFF schedule should be TU TH SA.

6. Press H+ to set the hour.
7. Press the clock button to set the schedule.
8. Press MAN(-) to set AMI to OFF OFF until you set the AMI up in the field, where you will

need to set it to AUTO OFF. Note: This will say AUTO ON if you are currently within the programmed ON period.

4. Maintenance

4.1 Check the AMI system

1. Check that the timer relay is reading the correct time.
2. Clean the solar panels to remove any dirt and leaves.
3. Clean the white board with water, if dirt builds up.
4. Check inside the grey box at the back of the AMI and inside the main aluminium box for

water ingress and insects to ensure it is still fully sealed.

5. Check there is no damage to the wires between the AMI and the solar panels/mains

power source.

6. Check that the LepiLED is working by pressing MAN(-) until the screen displays ON ON.

Remember to return it to AUTO OFF by continuing to press MAN(-).

7. Replace the desiccant bag in the battery box, if needed.

4.2 Changing the SSD hard drive Every few weeks, you will need to change the SSD card. You can change it less often if needed, but you this will increase the amount of data to be uploaded. The SSD card is located above the timer relay and plugged into the Raspberry Pi.

1. You can only change the SSD card when the system is switched off. Therefore, check on

the timer relay that it is on AUTO OFF.

a. If not, please turn the system by pressing MAN(-) until the screen displays OFF
OFF and wait until the lights on the Raspberry Pi stops flashing.
2. Unplug the SSD card from the Raspberry Pi and plug it into your computer. Open up the

folder containing the images and check that it has been populated and that the images look correct. Check the following:

a. Are the images lit evenly?
b. Are images in focus?
c. Are there any obstructions that you would be able to remove? Eg. long pieces of

grass.

d. Is the metadata correct? Have the pictures been taken at the right time?
3. Bring back the SSD card for data upload.
4. Plug in an empty SSD card to the AMI.
5. Make sure all SSD cards have been correctly labelled.

6. Take-down

6.1 In the field

1. Turn off the AMI on the timer relay by pressing MAN(-) until it reads OFF OFF.
2. Remove and label the SSD card.
3. Open the aluminium battery box and unplug the batteries.
4. Unscrew the solar wires from the terminals on the DIN rail with a flat-headed

screwdriver and pull the wires out of the battery box.

5. Unscrew the wires connecting the AMI to the battery box using a flat-headed

screwdriver.

a. The brown load fuse will need to be flipped up to gain access to the correct

screw.

b. Pull the wires out of the battery box â€“ there will be a conduit connector nut on

the inside of the battery box that will need to be unscrewed first.

6. Using the allen key to undo the screws attaching the AMI to the top of the battery box.

This must be done with care, as the AMI can easily fall to the ground as the last screw is removed.

7. Remove the batteries from the battery box.
8. Before removing the solar panels from the rigging, you will need to unlatch the 2 x

female connectors and 2 x male connectors. This can be done using the plastic wrench usually provided with solar connectors, or tweezers.

9. Remove the solar panels.
10. Take down the rigging and matting.

6.2 Storage

1. The AMIs should be stored indoors and upright.
2. Remove the watchdog battery from the electronics box (see Figure 8) at the back of the

AMI. Charge if needed.

3. Check the charge (voltage V) and capacity (ampere-hours Ah) of the car batteries.
a. Charge if needed.
b. Recondition if needed (under 60% of original Ah). If it is below 50%Ah and

reconditioning does not improve this, the battery cannot be used to power the AMI system.

7. Troubleshooting

7.1 Hardware

7.1.1 Power

If the raspberry pi is not turning on and the timer relay light is not on, there might be a problem with the power source, connection or fuse.

â€¢ Connections: Check that all connections are secure especially the stepdown cable

connecting the terminal block and the watchdog.

â€¢ Fuse: Check that the â€œdoorâ€ on the beige Output 1+ terminal in the battery box is tightly

closed. Also check that it holds a fuse when flipped up. If not present or if it has blown, there are spares in a plastic pocket attached to the SunSaver 20L which can be used to replace it.

â€¢ Power source: Within the battery box, look at the SunSaver 20L.
o If the status LED for the battery is red, then the battery is empty or low and if

there is no light, the battery has not been connected properly.

o Similarly, if the status LED for the solar panels is red (either flashing or solid)

there is an error with the panels.

o If all status LEDs are green, but the Raspberry pi remains off, you can use the

multimeter to test at which point the power is being interrupted. Unscrew the sunsaver and put the probes to the solar circuit, the battery circuit and the load circuit.

o Check that the solar wires are leading to the correct terminals (positive to 1+ and

negative to 1-, use multimeter if in doubt).

7.1.2 LepiLED

If the LepiLED or ring lights are not turning on, you should check the connections at the back of the camera/lighting box. You can do this by carefully unscrewing the gland and seeing if any of the wires are slack, especially the larger black cable which is a USB C cable connecting the camera. This can be plugged back in, if it has come loose. You should also check that the USB C cable and the two wires connecting the camera and lights are securely connected to the Raspberry pi in the electronics box.
